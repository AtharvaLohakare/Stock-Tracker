# 📈 Stock Price Tracker

A Python-based Stock Price Tracker that uses the Alpha Vantage API to fetch and display stock market information.

## 📌 About the Project

This project allows users to enter a stock symbol such as `IBM`, `AAPL`, or `MSFT` and get the latest available stock information.

The project was created to practice working with APIs, JSON data, Python functions, environment variables, and Git/GitHub.

## ✨ Features

- 🔎 Search for a stock using its symbol
- 💰 Display current stock price
- 📈 Display opening price
- 📊 Display highest price
- 📉 Display lowest price
- 📦 Display trading volume
- 📅 Display latest trading day
- 💵 Display previous closing price
- 🔄 Display price change
- 📊 Display percentage change
- 🔐 Secure API key using `.env`
- ❌ Handles invalid or unavailable stock data
- 🔁 Search multiple stocks without restarting the program

## 🛠️ Technologies Used

- Python
- Requests
- python-dotenv
- Alpha Vantage API
- Git
- GitHub
